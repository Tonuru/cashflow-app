# Cashflow per iPhone

Copia pubblicata della web app che si trova in `web/` del repository Cashflow (lì ci sono anche i test).
Qui c'è solo il codice: nessun dato, nessuna chiave. I dati restano negli Excel su OneDrive e in un Foglio Google del proprietario,
raggiungibile solo con il suo codice segreto.

Non modificare qui: le modifiche si fanno nel repository Cashflow e vengono ricopiate con `web/publish.sh`.
