# Cashflow per iPhone

Copia pubblicabile della web app che si trova in `web/` del repository Cashflow (lì ci sono anche i test).
Qui c'è solo il codice: nessun dato, nessuna chiave. I dati restano negli Excel su OneDrive e si leggono
solo dopo l'accesso con l'account Microsoft del proprietario.

Non modificare qui: le modifiche si fanno nel repository Cashflow e vengono ricopiate con `web/publish.sh`.
